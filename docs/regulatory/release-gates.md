# Release gates

A calculation may be marked `OFFICIAL` only when all of the following are approved:

1. source-to-report reconciliation
2. staging/default/SICR policy
3. segmentation
4. PD methodology and calibration
5. LGD methodology and recovery evidence
6. EAD/cash-flow method
7. scenario methodology
8. overlay governance
9. regulatory rule-pack sign-off
10. Finance / Risk / Internal Audit review
11. independent / external validation where applicable

Until then, all outputs must display `RESEARCH`, `SIMULATION` or `PRELIMINARY`.
